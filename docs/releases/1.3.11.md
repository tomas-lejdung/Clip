# Clip 1.3.11

Clip 1.3.11 makes the recording and Live Share controls more fluid while
keeping native viewer windows stable as they change size and state.

## Popovers and viewer windows

- Keep the menu-bar popover and Live Share controls stable while expanding,
  replacing, or returning from compact states.
- Improve native viewer window transitions and controls across resizing,
  reopening, and recording-state changes.
- Preserve viewer presentation state and source-resolution behavior as the
  native viewer changes layout.

## Requirements

Clip requires macOS 15 or later on Apple silicon. This build uses the same
stable Apple Development identity as previous updater releases.
