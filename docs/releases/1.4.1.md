# Clip 1.4.1

Clip 1.4.1 improves Live Share continuity and presentation without changing
the 1.4 room protocol or Web viewer.

## Window sharing

- Keep an exact-window share alive when its source moves to another macOS
  Space or becomes temporarily unavailable.
- Hold the last frame while the source is off-Space, then resume the same
  capture and WebRTC track when it returns.
- Stop the share when its source window is actually closed.
- Replay retained frames to newly connected or reconnected viewers so static
  and off-Space sources do not initially appear blank.
- Add **Bring Shared Windows to Front** to the floating sharing controls when
  another participant is sharing with you.

## Friends and collaboration

- Use saved friend names throughout Live Share, including participant lists,
  viewer windows, diagnostics, reconnect notices, and collaboration cursors.
- Keep friend aliases local to your Mac; authenticated room identities and
  transmitted participant descriptors remain unchanged.
- Center collaboration labels and shared-window toolbar controls more
  consistently.

## Interface polish

- Remove clipped shadows from the floating Share control and sharing HUD so
  their rounded materials render cleanly.

## Compatibility

Clip 1.4.1 uses the same Live Share protocol and server generation as Clip
1.4.0. No server update is required.

Clip requires macOS 15 or later on Apple silicon. This build uses the same
stable Apple Development identity as previous updater releases.
