# Clip 1.3.10

Clip 1.3.10 makes app-to-app Live Share sharper when a window from a standard
1× display is viewed on a Retina Mac.

## Native viewer

- Keep WebRTC's Metal drawable at the decoded video resolution so presentation
  scaling no longer blurs the source inside the video shader.
- Use nearest-neighbour sampling whenever shared content is enlarged, including
  standard-display shares shown at their native logical size on Retina.
- Continue using filtered scaling when Retina content is reduced for a smaller
  window or standard-density display.
- Snap tiny odd-dimension encoder differences to the intended integer scale
  instead of stretching every source pixel fractionally.

## Requirements

Clip requires macOS 15 or later on Apple silicon. This build uses the same
stable Apple Development identity as previous updater releases.
