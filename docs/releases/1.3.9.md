# Clip 1.3.9

Clip 1.3.9 brings Live Share much closer to source-display quality in both the
web and app viewers.

## Live Share quality

- Preserve the captured pixel dimensions through WebRTC instead of introducing
  point-versus-pixel scaling that softened text and UI edges.
- Render app-to-app shares at exact backing-pixel scale when they fit, with
  crisp integral scaling when the viewer window is resized.
- Seed new peer connections from the selected quality bandwidth so screen
  content stays sharper during scrolling and other high-motion updates.
- Expand stream diagnostics with source, capture, manifest, encoded-dimension,
  bitrate, QP, encode-time, and send-queue details.

## Color

- Carry Native Display color metadata through Clip's reviewed WebRTC build and
  apply it in the native Metal viewer.
- Keep compatible Rec.709 fallbacks for streams or displays that do not provide
  usable native color metadata.
- Update the web viewer protocol so browser and app viewers use the same source
  geometry and color contract.

## Requirements

Clip requires macOS 15 or later on Apple silicon. This build uses the same
stable Apple Development identity as previous updater releases.
