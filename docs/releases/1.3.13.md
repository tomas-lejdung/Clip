# Clip 1.3.13

Clip 1.3.13 makes fullscreen Live Share audio exclusions clear and easy to
control.

## Live Share audio

- Show **Exclude App Audio** as a full-size settings row with its current value
  aligned on the right.
- Display `None`, the selected application name, or the number of excluded apps
  directly in the popover.
- Keep the native application picker and live audio-exclusion behavior.

## Requirements

Clip requires macOS 15 or later on Apple silicon. This build uses the same
stable Apple Development identity as previous updater releases.
